# Orbital-mechanics-calculator
Python-based orbital velocity and period calculator using Astropy, Poliastro, and NumPy.
Orbital Mechanics Calculator

A Python-based orbital mechanics project developed independently to explore orbital velocity, orbital period, and the relationship between gravitational parameters and orbital motion.

Overview

This project uses Python and scientific computing libraries to calculate and compare orbital properties, including calculations based on the vis-viva equation.

Technologies

* Python
* NumPy
* Astropy
* Poliastro

Features

* Orbital velocity calculations
* Orbital period calculations
* Support for eccentricity inputs
* Comparison of library-derived and independently calculated results
* CSV output for further analysis

Background

Developed as an independent learning project while studying physics and astronomy, with an emphasis on applying mathematical principles to computational orbital mechanics.

Limitations

Results depend on the assumptions and orbital inputs used. Eccentric orbits require specifying the position along the orbit when interpreting instantaneous velocity.
